项目概览Project Overview

负责人 Jin Huang · 更新于 2026-06-03

概览Overview

  • 产品Product: macOS 菜单栏 JSON 工具，默认用 Cmd+Shift+J 呼出。A macOS menu-bar JSON toolkit, summoned by Cmd+Shift+J by default.
  • v1 目标v1 Goal: 贴近剪贴板工作流：粘贴、格式化、修复、复制。Stay close to the clipboard workflow: paste, format, fix, copy.
  • 隐私Privacy: 用户 JSON、本地历史、设置和 API key 默认保留在本机。User JSON, local history, settings, and API keys stay on the device by default.

SummarySummary

Jsonita 是给开发者、QA、产品技术同学使用的轻量 JSON 浮窗。它不是 IDE、Postman 或通用 AI 聊天工具；它解决的是日常复制粘贴 JSON 时的高频低摩擦问题。Jsonita is a lightweight JSON floating window for developers, QA, and technical product users. It is not an IDE, Postman, or a general AI chat tool; it solves high-frequency low-friction JSON clipboard work.

瞬时Instant

浮窗 P95 小于 500 ms，合法 JSON 预览 P95 小于 300 ms。Floating-window P95 under 500 ms and valid JSON preview P95 under 300 ms.

本地Local

SQLite、settings.json、window.json、secrets.json 都在用户数据目录。SQLite, settings.json, window.json, and secrets.json live in the user data directory.

聚焦Focused

v1 只做 JSON 处理、树视图、string 转换、历史和 DeepSeek Auto-Fix。v1 only covers JSON transforms, tree view, string conversion, history, and DeepSeek Auto-Fix.

BackgroundBackground

现有实现已经包含 Tauri 2、React 18、CodeMirror、SQLite FTS5、DeepSeek AI 修复和 macOS 原生窗口处理。文档的目标不是重新设计产品，而是把已确认的产品事实、实现约束和发布策略整理为可验证的 CAST 文档集。The current implementation already includes Tauri 2, React 18, CodeMirror, SQLite FTS5, DeepSeek AI repair, and native macOS window handling. The documentation goal is not to redesign the product but to cast confirmed product facts, implementation constraints, and release strategy into a verifiable CAST document set.

GoalsGoals

  • 用最少窗口切换完成 JSON 格式化、压缩、树视图、string 转换和复制。Complete formatting, minifying, tree viewing, string conversion, and copying with minimal window switching.
  • 非法 JSON 进入 AI Fix tab，用户看 diff 后再 Accept，不自动覆盖输入。Route invalid JSON into the AI Fix tab; users inspect the diff before Accept and input is not overwritten automatically.
  • 设置、快捷键、历史、窗口状态和 API key 的行为在 plan/spec 中可追溯。Make settings, shortcuts, history, window state, and API-key behavior traceable in plan/spec.

Proposed PlanProposed Plan
