● Valid JSON · 5 lines · 76 bytes History (12) · ⚙ Settings
  • 尺寸：首次呼出 920 × 560（克制 ── 不占满屏，初次也不太小）；min 720 × 480；max 由 4 层智能宽度策略决定，最大不超过屏宽 × 70% 且封顶 1400 px；可调整、记忆上次大小（详见 F10 浮窗智能宽度）
  • 位置 / 多屏：呼出在当前光标所在屏幕的中央偏上 1/3 处，不遮挡顶部菜单栏；v1 不记忆位置
  • 层级 / 切应用：始终置顶（NSPanel-like），不抢焦点、不被覆盖；⌘Tab 切应用时浮窗不消失
  • 失焦行为：默认自动隐藏，可在 General 设置关闭（必须可关，见 00_overview C 硬约束）

1.1Tab 切换

顶部功能 Tab：Format / Minify / Tree / →Str / →JSON；AI Fix 仅在 parse error 且 AI 可用时出现在最右。切换靠鼠标点击，或在非编辑态按 Tab 正向 / ⇧Tab 反向循环；焦点在 CodeMirror / 表单输入内时不拦截 Tab。active 状态 = 冷色焦点态。

单窗模式下切换 Tab 只改变待执行功能，不自动改写编辑器；右下角提示当前可按 ⌘Enter 执行 active Tab 并把结果写回输入区。

不绑定 ⌘1-⌘6 —— 避免污染系统级常用快捷键 + CodeMirror 编辑器内 ⌘+数字 冲突。

3呼出 → 处理 → 关闭 主流程

STEP 01
触发
按 ⌘⇧J 或点击菜单栏图标
→
STEP 02
浮窗出现
150 ms 淡入；输入框聚焦；剪贴板若含 JSON 则自动粘贴
→
STEP 03
处理
debounce 300 ms 后实时格式化 + 右侧同步渲染树状视图
→
STEP 04
关闭
编辑器内第一下 Esc 退出 editing；非编辑态 Esc / 失焦 / ⌘W → 隐藏浮窗；合法内容由实时 transform 持久化为「上次会话」

4AI Fix 流程（仅错误时）

STEP 01
检测失败
JSON parse 失败 → 状态栏变红 + 「AI Fix」按钮出现
→
STEP 02
点击
按钮 loading；调 DeepSeek（不做客户端节流，透传上游 429）
→
STEP 03
本地验证
try-parse 返回；非法 → 显示原始返回供调试
→
STEP 04
用户决定
diff 展示修复点 → 接受 / 撤销
