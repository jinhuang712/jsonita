组件库映射

shadcn/ui 复用清单 + 自定义组件清单 + 每个组件的 token / props / 状态完整定义。

1策略

  • shadcn/ui 是源码不是依赖 ── 按需 npx shadcn@latest add <component> 拷贝到 src/ui/<name>.tsx，再改样式让它指向我们的 02 设计令牌 token
  • 基元用 shadcn（Button / Input / Select / Switch / Dialog / Tooltip / DropdownMenu / Tabs / ScrollArea）
  • 业务组件自写（Editor / TreeView / TabBar / StatusBar / Toast / HistoryItem 等）
  • 不引 antd / Mantine / Chakra ── bundle 太大且风格冲突

4.3Toast

基于 sonner 封装，四 variant 对应四种状态色：

// src/shell/Toast.tsx
import { toast as sonnerToast } from 'sonner';

export const toast = {
  info:    (m: string, opts?: ToastOpts) => sonnerToast(m, { ...opts, className: 'toast-info' }),
  ok:      (m: string, opts?: ToastOpts) => sonnerToast.success(m, { ...opts, className: 'toast-ok' }),
  warn:    (m: string, opts?: ToastOpts) => sonnerToast.warning(m, { ...opts, className: 'toast-warn' }),
  danger:  (m: string, opts?: ToastOpts) => sonnerToast.error(m, { ...opts, className: 'toast-danger' }),
};

interface ToastOpts {
  description?: string;
  action?: { label: string; onClick: () => void };
  duration?: number;        // 默认 5000；带 action 时 8000
}

样式（global.css）：

.toast-info    { background: var(--info-bg);   border-color: var(--info);   color: var(--info); }
.toast-ok      { background: var(--ok-bg);     border-color: var(--ok);     color: var(--ok); }
.toast-warn    { background: var(--warn-bg);   border-color: var(--warn);   color: var(--warn); }
.toast-danger  { background: var(--danger-bg); border-color: var(--danger); color: var(--danger); }
[data-sonner-toast] {
  border-radius: var(--radius-md);
  border-width: 1px;
  border-style: solid;
  font-size: var(--fs-sm);
  padding: var(--sp-3) var(--sp-4);
  box-shadow: var(--shadow-md);
}

4.7ShortcutInput

interface ShortcutInputProps {
  value: string;            // "Cmd+Shift+J" 风格
  onChange: (next: string) => void;
  onConflict?: (info: ShortcutRegisterResp) => void;
}

录入 UX：

  1. 未聚焦：显示当前值，hover 高亮可点
  2. 聚焦：变红色提示 "Press keys to record..."；listen keydown
  3. 用户按下组合（如 ⌘⇧J）：解析 modifiers + key → 调 shortcut_register 验证
  4. 冲突：变红 + Tooltip 提示 Already used by {with_app || "system"}，不写入
  5. 成功：变绿 1s 后回 default 状态

interface ApiKeyInputProps {
  hasKey: boolean;          // 已存 Keychain 时为 true

6状态变体清单（横向核验）

所有交互组件必须实现完整 6 态：

态判定视觉变化
default无交互token 默认值
hover鼠标悬停bg → soft / cursor pointer
focus-visible键盘聚焦+ box-shadow: var(--shadow-focus)
active按下中opacity 0.9 / scale 0.98
disabled不可点opacity 0.5 + cursor not-allowed
loading异步进行中+ Spinner + 文字微调 / pointer-events none
WARN

不要用 :focus 而要用 :focus-visible ── 避免鼠标点击也出现 focus ring。所有 shadcn 组件已用 :focus-visible，自写组件须同步。
