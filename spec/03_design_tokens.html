SPEC · 章节 03

设计令牌

颜色 / 字体 / 间距 / 圆角 / 阴影 / 动效 ── light · dark 双主题的完整 token 系统。

1设计语言锚点

Jsonita 的视觉语言锚定在四点上，所有 token 取值都为之服务：

要表达 · Express

  • 极简克制 ── 不装饰，编辑器和数据是主角
  • macOS native 气质 ── SF Pro · 系统 blur · vibrancy 风
  • 开发者审美 ── mono 字体多用 · 类型颜色清晰
  • 瞬时清晰 ── 状态色不饱和但识别度高（红=错，绿=有效）

避免 · Avoid

  • 大色块 / 渐变背景 ── 浮窗保持极轻
  • 多种品牌色 ── 蓝是唯一 primary，橙是唯一 accent
  • 圆角 ≥ 16px 的"App"感 ── 文档卡片最多 10px
  • 动效 > 200ms ── 工具应即时响应

8主题切换机制

8.1三态：System / Light / Dark

设置项 settings.theme: 'system' | 'light' | 'dark'，默认 'system'。

STEP 01
读 settings
启动时调 settings_get_all() → theme
→
STEP 02
解析有效值
system → 查 prefers-color-scheme
→
STEP 03
挂 data-theme
document.documentElement.dataset.theme = 'light' / 'dark'
→
STEP 04
订阅变化
listen 'theme:system_changed' + matchMedia change

8.2实现要点

// src/theme/ThemeProvider.tsx（关键片段）
function resolveTheme(setting: ThemeMode): 'light' | 'dark' {
  if (setting === 'system') {
    return window.matchMedia('(prefers-color-scheme: dark)').matches
      ? 'dark' : 'light';
  }
  return setting;
}

useEffect(() => {
  const apply = () => {
    const eff = resolveTheme(settings.theme);
    document.documentElement.dataset.theme = eff;
    // 同步给 CodeMirror（编辑器另开 theme extension）
    editorStore.setTheme(eff);
  };
  apply();

  if (settings.theme === 'system') {
    const mql = window.matchMedia('(prefers-color-scheme: dark)');
    mql.addEventListener('change', apply);
    return () => mql.removeEventListener('change', apply);
  }
}, [settings.theme]);

8.4避免主题切换闪烁

HTML 头部内联一段 script（在 React 挂载前）读 localStorage cache 中的 theme，先设 data-theme，再加载主 bundle ── 避免 FOUC。

<script>
(function() {
  try {
    var t = localStorage.getItem('jsonita.theme.effective') || 'light';
    document.documentElement.dataset.theme = t;
  } catch (e) {}
})();
</script>

11命名一致性规则

  • 所有 token 用 --kebab-case
  • 语义优先于具体值：用 --danger 不用 --red-500
  • 三档命名 = base / soft / strong（如 border / border-strong）
  • 状态色"背景"统一加 -bg 后缀（--ok-bg）
  • 编辑器专属 token 都以 --editor-* 前缀
  • JSON 高亮以 --json-* 前缀
  • 不要用 --color-* / --font-size-* 这种冗长前缀；语义已经够清楚
