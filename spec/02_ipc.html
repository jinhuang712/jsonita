SPEC · 章节 02

IPC 合约

前后端通信契约：所有 commands / events 的完整签名表，含错误分支与时序。

1设计原则

  • 命名：Rust 命令用 snake_case（json_format）；前端调用时同名。事件用冒号分隔（window:shown / ai:progress）
  • 同步语义：所有 command async；前端可放心 await invoke()。CPU 密集操作内部用 spawn_blocking
  • 错误统一：所有 command 返回 Result<T, JsonitaError>，error 类型见 00 § 6
  • 大小限制：command payload < 4 MB；> 4 MB 改用 event 流式分块（v1 未触发，预留）
  • 幂等性：所有 read 操作幂等；write 操作通过 request_id 字段去重（v1 仅 ai_fix 用到）

  indent: IndentMode;
  sortKeys: boolean;
  trailingNewline: boolean;
}

export interface UnwrapOpts {
  timeoutMs: number;
  maxDepth?: number;
}

  quote: QuoteStyle;
  escapeUnicode: boolean;

  return invoke('json_format', { text, opts });

  return invoke('json_minify', { text });

}
export async function jsonStringify(text: string, opts: StringifyOpts): Promise<string> {
  return invoke('json_stringify', { text, opts });

3.1TS 监听封装

// src/ipc/events.ts
import { listen, type UnlistenFn } from '@tauri-apps/api/event';

type EventMap = {
  'window:shown':            WindowShown;
  'window:hidden':           Record<string, never>;
  'shortcut:restore_last':   Record<string, never>;
  'settings:changed':        Settings;
  'ai:progress':             AiProgress;
  'history:updated':         Record<string, never>;
  'theme:system_changed':    { mode: 'light' | 'dark' };
  'app:will_quit':           Record<string, never>;
};

export function on<K extends keyof EventMap>(
  name: K,
  handler: (payload: EventMap[K]) => void,
): Promise<UnlistenFn> {
  return listen<EventMap[K]>(name, (e) => handler(e.payload));
}

6类型同步策略

Rust struct 与 TS interface 手工保持镜像（v1 不引入 ts-rs 等自动生成）。

INFO

放弃自动生成的理由：本项目只有 ~30 个 struct，手写一份 src/types/*.ts 维护成本可控；引入 ts-rs 会增加 build 复杂度（需 cargo test 触发生成）。v2 体量上来再换。

变更流程：

  1. 改 Rust struct 时，同步改 src/types/*.ts
  2. PR 模板检查："IPC types updated?" 复选框
  3. CI 加一个 smoke test：浮窗启动 + 调每个 command 一次，验证 (de)serialize

7性能与限流

  • 前端 debounce：编辑器 onChange → format/parse 调用，统一 300 ms debounce（见 00 § 5.1）
  • 后端不主动节流：所有 command 来一个跑一个；CPU 密集走 spawn_blocking
  • AI 不限频：依 plan/01 F4，用户用自己 key，仅透传上游 429
  • SQLite WAL：所有 read 并发；write 串行（rusqlite + single connection per thread + r2d2 pool）
