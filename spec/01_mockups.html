11浮窗智能宽度（plan F10）

4 层逻辑（首次 / 粘贴扩 / 拖动 / soft-wrap）的视觉示意。克制：最大不占满屏 · 初次不能太小。详细算法见 06 § 9 智能宽度。

11.2层 2 ── 粘贴后自动扩宽

maxLineChars计算ideal_w行为
≤ 80不触发—保持当前
100100×8+64864 px仍为 920（已大于 ideal，不缩）
160160×8+641344 px920 → 1344（150ms 动画）
2401984clamp(720, min(1400, 屏宽×70%))13" 屏 → 1008；27" 屏 → 1400
Input · 160 ch 长行
{"description":"a very long single-line description that triggers auto-widen","ok":true}
Output
{
  "description": "a very long ...",
  "ok": true
}
● Valid JSON · auto-widened to 1344 px⚙

11.3层 3 ── 手动拖动锁定

  • 用户拖动后立即写 window.json + user_dragged = true
  • 下次呼出沿用
  • 之后再粘贴长内容 不再自动扩宽 ── 用户尺寸锁定
  • 设置 General "重置浮窗尺寸" 按钮可清

11.4层 4 ── soft-wrap 跳过自动扩宽

soft-wrap = on（默认）→ 长行换行不溢出，不需要扩宽，层 2 跳过。soft-wrap = off → 长行水平滚动，层 2 触发扩宽。

12Tree 节点 Hover 复制（plan F2 · spec 08 § 4.5）

hover 任意节点 → 行尾出现 📋。leaf 复制 raw value；object/array 递归复制 pretty JSON。

light · 悬停在 leaf "alice"
Tree · hover 行尾 📋
▾ root{2}
▾ user{2}
name: "alice"
age: 30
▾ items[2]

点 📋 → 剪贴板 = "alice"（带引号 raw）→ Toast "Copied"

dark · 悬停在 object root
Tree · hover 行尾 📋
▾ root{2}
▾ user{2}
name: "alice"
age: 30
▾ items[2]

点 📋 → 剪贴板 = 整个 subtree pretty JSON（含 user / items）

复制内容规则：

node 类型剪贴板内容
string leaf带引号 raw："alice"
number leaf字面量：30
bool leaftrue / false
null leafnull
object / array node（含 root）递归 pretty-print 2 空格缩进 JSON

键盘可达：聚焦节点行按 ⌘C 等同于点 📋。点击 key 文字本身仍复制 path（如 user.name），两者独立。
