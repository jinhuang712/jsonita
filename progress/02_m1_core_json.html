RISK

M1 是本项目最重的实施 Phase ── 9 节点 + 12 退出条件。下列风险触发概率较高。

风险触发场景规避 / 应急
CodeMirror 6 与 React 18 strict mode double-mount 冲突dev 模式重复 effect 导致 editor 实例泄漏 / undo 丢用 ref + 单次 init；strict mode 不要关 ── 用 useEffect 严谨清理
