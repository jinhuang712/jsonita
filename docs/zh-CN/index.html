功能

你每天重复的那 9 个 JSON 琐事——一键搞定。

不用打开编辑器、不用开浏览器标签、不用敲 CLI 管道。Jsonita 把那些无聊但高频的转换做干净,然后立刻退场。

格式化与压缩,随心所欲。

缩进 2 / 4 / Tab、按 key 排序、行尾换行——全部可配。粘贴长行时浮窗自动加宽,让你真的能看清内容,而不是盯着被折行的一整段。

  • 缩进 2 / 4 / Tab、按 key 排序、行尾换行开关
  • 智能宽度:长行自动扩窗,短行缩回到舒适尺寸
  • ⌘ ↵ 复制结果;⌘ \ 单栏 / 双栏切换

树形视图 + 多层字符串解包。

折叠数组、一眼看清类型。粘进被 Go / Python / Java proto 包了两三层的 escape 字符串,Jsonita 一次解开所有包裹层——全局 60 秒超时兜底,永远不会把你卡死。

  • 只读树形视图,值按类型染色
  • 一键解开多层转义 / stringify 包裹的 payload
  • 可配置:粘贴字符串时自动解包

AI 自动修复——只在你按下时才发生。

粘到一段几乎是 JSON 的日志或 Slack 片段?Jsonita 会显示 AI 修复标签,你点击后会先看 diff,再决定是否接受。在你点那个按钮之前,任何东西都不会离开你的机器。

  • OpenAI 兼容 + Anthropic 双协议,用你自己的 API key
  • 展示前会先过本地 JSON 校验
  • Diff 预览 · 取消一字不动保留你的原文

下载

开始用 Jsonita。

v1.0 beta · macOS 为主,Windows 为 beta。macOS 签名包与 Homebrew 会在 v1.1 提供。

macOS
  1. 从 GitHub Releases 下载最新的 .dmg。
  2. 打开后将 Jsonita.app 拖到 /Applications。
  3. 启动一次,然后任意位置按 ++J。
