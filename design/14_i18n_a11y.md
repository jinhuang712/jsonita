# 国际化 & 无障碍

i18n 架构准备（v1 英文 → M3 中文）+ a11y 清单 ── 先讲设计与回退策略，再列资源结构与 a11y 要求。

REF

本章是 横切关注章节：v1 仅交付英文 UI（ [plan/04 NFR § 3](../plan/04_nfr.md) ），但 v1 实施期就要锁定 lib 选型、资源结构、切换机制 ── 否则 M3 中文 UI 会引发大量返工（key 拆分 / 文案外移 / 字体回退调整）。 `settings.locale` 字段补充见 [13 § 3.3](../spec/13_schemas.md)；字体栈见 [03 § 6.1](03_design_tokens.md)。

一 · 设计

## 1设计目标与边界

i18n 在 Jsonita 是 架构准备 而不是 v1 功能 ── 五条硬约束：

| 原则 | 含义 | 实现影响 |

| --- | --- | --- |

| v1 实施期 lock | v1 仅交付英文，但所有 UI 文案 必须经 `t()` 函数 ── 不允许 hardcode 英文字符串 | M0 起就引 react-i18next，所有组件按规范写 |

| Rust 端不翻译 | Rust 返回的错误 `JsonitaError` 永远是英文 + `kind`；翻译在前端按 kind 映射 | 跨 IPC 协议稳定，不受语言切换影响； `error.kind` 是契约的一部分（ [13 § 1](../spec/13_schemas.md) ） |

| JSON 内容不受 i18n 影响 | 用户输入的 JSON 中含 CJK / 阿语 / 表情 ── 永远透传，编辑器渲染由 CodeMirror 处理 | i18n 只影响 chrome（菜单 / 按钮 / 状态栏 / Modal；Toast 为保留设计） |

| 实时切换 | 用户切语言 → React 全量 re-render， 无需 reload 窗口 | 所有文案经 hook 订阅 store，避免硬编码 prop drilling |

| 包内置不下载 | 语言包打入 bundle（不从远程拉）── 离线可用，且符合 v1 "不联网" 约束 | v1 / M3 都是 2 个 locale (en-US / zh-CN)，bundle 体积可控（每 locale ~10 KB） |

## 2关键设计决策

### 2.1i18n lib 选型

| 方案 | 体积 | 类型友好 | 命名空间 | 结论 |

| --- | --- | --- | --- | --- |

| react-i18next （选） | ~30 KB gzipped | TS plugin 提供 key 自动补全 | 原生 namespace + 懒加载 | 生态最熟；与 zustand 兼容；fallback chain 内置 |

| lingui | ~15 KB | 编译期提取 key（macro） | 需自己组织 | 体积小但 macro 增加 build 复杂度；ICU MessageFormat 对我们简单场景过度 |

| react-intl (FormatJS) | ~50 KB（含 ICU runtime） | OK | 需自己组织 | 体积偏大；ICU 强大但 Jsonita 不需要复数 / 性别变体等高级特性 |

| 自写 | ~2 KB | 无 | 无 | 省体积但要自维护 fallback / 复数 / 格式化 / TS 类型 ── 性价比低 |

### 2.2资源 namespace 划分

按 章节模块 拆 namespace，而非按"类型"（按钮 / 标签 / 错误）拆。理由：组件改名 / 移位时改文案文件位置和组件位置一致，定位快。

| namespace | 覆盖范围 | 典型 key |

| --- | --- | --- |

| `shell` | FloatingWindow / TabBar / StatusBar | `shell.tabBar.format` ·`shell.statusBar.valid` |

| `panes` | 5 个功能面板的标题、placeholder、empty state | `panes.tree.emptyState` ·`panes.aiFix.acceptButton` |

| `settings` | 设置 Modal + 6 个分组 + 字段标签 | `settings.general.launchAtLogin` ·`settings.ai.testConnection` |

| `history` | 保留 namespace；历史 Modal / Item UI 当前未实现 | `history.filterPinned` ·`history.confirmClear` |

| `errors` | `JsonitaError` 9 个 kind 映射 + UI 行动文案 | `errors.parse.title` ·`errors.rateLimit.retryAfter` |

| `about` | About 页（版本 / 链接 / 致谢） | `about.version` ·`about.openSourceCredits` |

| `common` | 跨 namespace 通用词（OK / Cancel / Confirm / 12 个 base） | `common.ok` ·`common.cancel` |

### 2.3locale 检测与切换

三层 fallback chain，显式优先于隐式：

| 条件 | 选择 |

| --- | --- |

| `settings.locale` 已设置 | 使用 `settings.locale` |

| 首次启动或 reset，且 `navigator.language` 是 `zh-CN` 或 `zh-*` | 使用 `zh-CN` |

| 首次启动或 reset，且浏览器语言不匹配支持列表 | 使用 `en-US` |

| locale 已解析 | 执行 `i18n.changeLanguage(locale)`，同步 `document.documentElement.lang`，React 全量 re-render |

切换时机：用户在 Settings → General → Language 改 locale →`settings_set({ locale: 'zh-CN' })` → Rust emit `settings:changed` → 前端 store update →`i18n.changeLanguage` → React 重渲染。无需 reload 窗口。

### 2.4Rust 错误为何不翻译

kind 是契约 ： `JsonitaError.kind` 是跨 IPC 的稳定标识符（ [13 § 1](../spec/13_schemas.md) ），用于调用方错误处理与 UI 呈现（ [02 § 3.3](../spec/02_ipc.md) ）。若 Rust 翻译，前端按 kind 映射文案的链路就被打破

错误日志稳定 ：日志和 issue 报告中错误信息都是英文 + kind，便于跨语言用户提交 bug

前端单源 ：所有用户文案都在 `errors.*` namespace，集中维护

映射示例：Rust 返 `{ kind: 'RateLimit', data: { retryAfterSec: 30 } }` → 前端 `t('errors.rateLimit.retryAfter', { sec: 30 })` → 中文显示"请 30 秒后重试"。

二 · 工作机制

## 3加载与切换数据流

加载与切换数据流：

| 阶段 | 步骤 |

| --- | --- |

| 启动加载 | `src/index.html` bootstrap 后调 `settings_get_all`，按 § 2.3 fallback resolve locale |

| 初始化 | `i18n.init` 动态 import 当前 locale 资源，再 `ReactDOM.render` |

| 文案订阅 | 所有 `useTranslation` hooks 通过 `t(namespace.key, params)` 读取资源 |

| 运行时切换 | 用户改 locale 后调 `settings_set({ locale })` |

| 后端广播 | Rust emit `settings:changed` |

| 前端更新 | settings store update，执行 `i18n.changeLanguage(locale)` |

| 渲染结果 | React re-render，所有文案订阅自动刷新 |

### 3.1资源懒加载

启动只加载 当前 locale 的全部 namespace（en-US 或 zh-CN）。切换到另一 locale 时 dynamic `import()`，首次切换会有一次 ~10 KB 异步加载 ── 用户感知不到（< 50 ms）。

## 4字体回退机制

这是 i18n 章节里 最容易翻车 的设计点 ── mono 字体（SF Mono / JetBrains Mono / Cascadia Code） 都不含 CJK 字符。处理不当会让中文 chrome 渲染成方框或回退到衬线字体（视觉不一致）。

### 4.1三种字符场景

| 字符场景 | 出现位置 | 字体栈 | 结果 |

| --- | --- | --- | --- |

| ASCII 或 latin | chrome UI：menu、button、label | font-sans；SF Pro 优先，末尾含 PingFang SC / Microsoft YaHei UI | 正常渲染 |

| CJK | chrome UI：menu、button、label | font-sans；SF Pro 不含 CJK 时逐字符回退到 PingFang SC / Microsoft YaHei UI | 中文不方框，不回退到衬线 |

| ASCII 或 latin | mono 区域：编辑器、树、code | font-mono；SF Mono / JetBrains Mono / Cascadia Code 优先 | 等宽渲染 |

| CJK | mono 区域：编辑器、树、code | font-mono 末尾追加 PingFang SC / Microsoft YaHei UI | CJK 字符变宽但行高一致，视觉可接受 |

### 4.2关键调整

03 § 6.1 字体栈已基本覆盖此场景（已含 `PingFang SC` /`Microsoft YaHei UI` 在 sans 栈末尾）。 需要在 14 章新增 的事：

`--font-mono` 栈末尾追加 `"PingFang SC", "Microsoft YaHei UI"` ── CJK 字符在编辑器 / 树视图也能 fallback 渲染（不出现方框）

JSON 树视图 fs 微调：tree-view 当字符包含 CJK 时整行高度可能略升 ── 不调，让 line-height 1.7 自然吸收

错误信息中包含 CJK：state bar fs 12.5 px + line-height 1.4 → CJK 字符勉强可读， 不需要 另开 fs；如视觉差再升 fs-sm（13）

placeholder 文案 i18n：所有 `<input placeholder="...">` 必须用 `t()` ，不能 hardcode

三 · 契约

## 5资源结构

### 5.1目录组织

| 路径 | 内容 |

| --- | --- |

| `src/i18n/index.ts` | i18n.init() + 配置 + 类型增强（让 TS 推 key autocomplete） |

| `src/i18n/en-US/{shell,panes,settings,history,errors,about,common}.json` | 7 个 namespace × 1 个 locale = 7 个文件 |

| `src/i18n/zh-CN/{...}.json` | 同上 7 个 namespace（M3 添加） |

| `src/types/i18n.d.ts` | `declare module 'react-i18next'` 的 resources 类型增强（基于 en-US 推 key 类型） |

### 5.2资源 JSON 示例

```

// src/i18n/en-US/errors.json ── 部分
{
  "parse": {
    "title": "JSON parse error",
    "atLineCol": "Line {{line}}, Col {{col}}: {{msg}}",
    "actionAiFix": "Try AI Fix"
  },
  "rateLimit": {
    "title": "Rate limited",
    "retryAfter": "Please retry in {{sec}}s",
    "actionWait": "Waiting…"
  },
  "aiInvalidJson": {
    "title": "AI returned invalid JSON",
    "actionCopyRaw": "Copy raw",
    "actionRetry": "Retry"
  }
}

```

### 5.3初始化骨架（≤ 20 行）

```

// src/i18n/index.ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';

const NS = ['shell', 'panes', 'settings', 'history', 'errors', 'about', 'common'];

export async function initI18n(locale: 'en-US' | 'zh-CN') {
  const resources = Object.fromEntries(
    await Promise.all(NS.map(async (ns) => [
      ns, (await import(`./${locale}/${ns}.json`)).default,
    ]))
  );
  await i18n.use(initReactI18next).init({
    lng: locale, fallbackLng: 'en-US',
    resources: { [locale]: resources },
    interpolation: { escapeValue: false },  // React 已自动 escape
    ns: NS, defaultNS: 'common',
  });
}

```

### 5.4组件使用示例（≤ 15 行）

```

// src/shell/StatusBar.tsx ── 使用 useTranslation
import { useTranslation } from 'react-i18next';

export function StatusBar({ status, errorLoc }: StatusBarProps) {
  const { t } = useTranslation('shell');  // namespace = shell
  if (status === 'error' && errorLoc) {
    return <span>
      ● {t('statusBar.invalid')} · {t('statusBar.line')} {errorLoc.line},
        {t('statusBar.col')} {errorLoc.col}
    </span>;
  }
  return <span>● {t('statusBar.valid')}</span>;
}

```

## 6settings 字段补充

[13 § 3.3](../spec/13_schemas.md) Settings struct 需要新增字段（M0 起就支持，v1 只允许 `en-US` ── M3 解锁 `zh-CN` ）：

| 字段 | 类型 | 默认 | UI 位置 |

| --- | --- | --- | --- |

| `locale` | `'en-US' \| 'zh-CN'` | auto-detect（§ 2.3） | 设置 General → Language Select |

对应 Rust enum：

```

// src-tauri/src/types.rs ── 同步加入
#[derive(Serialize, Deserialize, Clone, Copy)]

pub enum Locale { EnUs, ZhCn }   // serialize: "en-us" | "zh-cn"

```

四 · a11y 清单

## 7a11y 强制要求

| 类别 | 要求 | 实现位置 |

| --- | --- | --- |

| 键盘可达 | 所有交互元素可通过 Tab 序列到达；无键盘陷阱 | shadcn 默认满足；自定义组件须保持（ [04 各组件 props](04_components.md) ） |

| focus-visible | 只在键盘聚焦时显示 focus ring，不在鼠标点击时显示 | 所有组件用 `:focus-visible` 而非 `:focus` （ [04 § 6](04_components.md) ） |

| ARIA labels | 纯图标按钮（settings 等）必须有 `aria-label` | 状态栏按钮；HistoryItem 为保留设计 |

| ARIA live regions | 状态栏动态变化用 `role="status"` 或 `aria-live="polite"` 让屏阅器朗读；未来 Toast 也应遵守 | StatusBar |

| 语义化 HTML | 用 `<button>` 不用 `<div onClick>`；用 `<nav>` /`<main>` 等 landmark | 所有自写组件 |

| 对比度 | 所有正文文本 ≥ AA（4.5:1）；body text ≥ AAA | 已核验，见 [03 § 5](03_design_tokens.md) |

| reduced motion | `prefers-reduced-motion: reduce` 时动画时长 → 1 ms | 已实现，见 [03 § 9.1](03_design_tokens.md) |

| 高对比度模式 | v1 不专门支持 Windows 高对比模式；macOS Increase Contrast 通过 token 设计满足 | — |

| 缩放 | UI 至 200% zoom 不破布局 | 所有间距 / 字号用 px（不用 vw / vh） |

| 语言声明 | `<html lang="...">` 随 locale 切换 | i18n.changeLanguage 时同步 |

## 8screen reader 关键流

三条核心交互必须通过 screen reader（VoiceOver）测试：

呼出浮窗 → 编辑器获焦 ：用户应听到"JSON editor, edit text" + tabBar 当前激活 Tab 名

parse 错误 ：状态栏 `aria-live="polite"` → 自动朗读 "Invalid JSON, Line 3, Col 12"；详细 reason 由 inline lint tooltip 承载

AI Fix 完成 ：DiffView Accept/Reject 按钮可 Tab；错误文本在 AI 面板内可读，未来 Toast 接入后再补 `role="status"`
